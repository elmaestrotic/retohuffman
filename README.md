# retohuffman

Simulador del algoritmo de Huffman de punta a punta: frecuencias → lista enlazada ordenada → árbol tradicional → árbol canónico → bits, bytes y hexadecimal → encabezado → descompresión. Incluye un **modo reto** para resolverlo antes de ver la respuesta.

- Sitio: https://elmaestrotic.github.io/retohuffman/
- Versión socrática anterior: [`reto-socratico.html`](reto-socratico.html)
